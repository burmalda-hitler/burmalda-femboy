🛡️ Fake AdBlock (Troll Edition)
Данное браузерное расширение визуально маскируется под стандартный блокировщик рекламы (AdBlock), однако истинное предназначение проекта — пранки и троллинг.
> ⚠️ ОТКАЗ ОТ ОТВЕТСТВЕННОСТИ: Проект создан исключительно в образовательных и развлекательных целях. Ответственность за любое неправомерное использование данного программного обеспечения не несется.
> 
✨ Особенности
 * 🎭 Полная маскировка: Иконки, название и описание в браузере копируют популярный блокировщик рекламы, чтобы не вызывать подозрений.
 * 🔗 Кастомный редирект: Скрипт принудительно открывает заранее заданную ссылку.
 * 📦 Готово к использованию: По умолчанию в коде установлена ссылка на страницу Викисклада с фотографией фембоя.
⚙️ Настройка (Смена ссылки)
Для того чтобы изменить ссылку, открываемую расширением, пользователю необходимо отредактировать два файла: background.js и content.js.
Требуется открыть эти файлы в любом текстовом редакторе и заменить базовый URL на желаемый. Базовая конфигурация выглядит следующим образом:
// Фрагмент кода для замены в background.js и content.js
 "https://commons.wikimedia.org/wiki/File:FemboyPup_in_bed.jpg?uselang=ru";

🚀 Установка
Для установки расширения в браузер на базе Chromium (Chrome, Edge, Brave, Яндекс.Браузер) требуется выполнить следующие шаги:
 * Скачать данный репозиторий в виде ZIP-архива и распаковать файлы, либо клонировать репозиторий через Git.
 * Открыть в браузере страницу управления расширениями (ввести в адресную строку chrome://extensions/).
 * Активировать «Режим разработчика» (Developer mode) в правом верхнем углу.
 * Нажать кнопку «Загрузить распакованное расширение»
 * Выбрать папку, в которой находятся файлы расширения.

🎯 Использование

После успешной установки расширение начнет работать в фоновом режиме. Визуально программа не будет выдавать истинную природу, но при срабатывании скриптов будет открываться заданная ссылка. Инструмент отлично подходит для установки на устройства, временно оставленные без присмотра.
